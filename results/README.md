# Experiment results

Эта директория хранит компактные, отслеживаемые Git результаты экспериментов. Один эксперимент —
одна датированная поддиректория с манифестом, точными агрегатами и ссылками на тяжёлые артефакты.

## Соглашение

- `manifest.json` — происхождение результатов, commit и внешние run IDs;
- `runs.json` — конфигурации запусков и все скалярные метрики;
- `benchmark_metrics.csv` — одна строка на run × benchmark;
- `source_metrics.csv` — детальная разбивка по MATH/MMLU subsets и другим источникам;
- `paired_comparison.csv` — попарное сравнение режимов на одних и тех же примерах;
- `paired_source_comparison.csv` — то же сравнение по отдельным источникам;
- `README.md` — краткий отчёт и интерпретация.

Полные completions и prediction-таблицы не коммитятся: это тяжёлые артефакты, которые остаются
в W&B. Их run IDs и прямые ссылки обязательно фиксируются в архиве.

## Эксперименты
